# 🏨 Grand Palace Hotel Management System

A full-stack MERN web application designed to digitally manage hotel operations, including room booking, guest management, and role-based access control.

## 🚀 Project Overview
Grand Palace Hotel Management System is a production-ready application providing distinct features for Admin, Staff, and Guests. The entire application is deployed on the cloud and is accessible 24/7.

## 🛠️ Technology Stack
* **Frontend:** React.js 
* **Backend:** Node.js + Express.js 
* **Database:** MongoDB Atlas 
* **Authentication:** JWT (JSON Web Token) & bcryptjs
* **Deployment:** Vercel

## ⚡ Key Features
* **Role-Based Access Control:** Secure access for Admin, Staff, and Guests.
* **Room Management:** Manage 8 room types with real-time availability and dynamic pricing.
* **Booking System:** Seamless check-in/out, automatic GST calculation, and double-booking prevention.
* **Loyalty Program:** Tiered rewards system (Bronze to Platinum) for guest retention.
* **Admin/Guest Dashboards:** Intuitive stats for admins and booking history for guests.

## 🔒 Security
* JWT-based authentication with 7-day token expiry.
* Password hashing using bcryptjs (Salt rounds: 10).
* Protected routes and input validation across all forms.
