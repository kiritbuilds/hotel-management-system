# 🏨 Grand Palace Hotel Management System

A full-stack MERN web application designed to digitally manage hotel operations, including room booking, guest management, and role-based access control.

## 🚀 Project Overview
Grand Palace Hotel Management System is a production-ready application providing distinct features for Admin, Staff, and Guests. The entire application is deployed on the cloud and is accessible 24/7.

## 🛠️ Technology Stack
* **Frontend:** React.js (v18.x)[cite: 1]
* **Backend:** Node.js + Express.js (v22.x/4.x)[cite: 1]
* **Database:** MongoDB Atlas (Cloud)[cite: 1]
* **Authentication:** JWT (JSON Web Token) & bcryptjs[cite: 1]
* **Deployment:** Vercel[cite: 1]

## ⚡ Key Features
* **Role-Based Access Control:** Secure access for Admin, Staff, and Guests[cite: 1].
* **Room Management:** Manage 8 room types with real-time availability and dynamic pricing[cite: 1].
* **Booking System:** Seamless check-in/out, automatic GST calculation, and double-booking prevention[cite: 1].
* **Loyalty Program:** Tiered rewards system (Bronze to Platinum) for guest retention[cite: 1].
* **Admin/Guest Dashboards:** Intuitive stats for admins and booking history for guests[cite: 1].
